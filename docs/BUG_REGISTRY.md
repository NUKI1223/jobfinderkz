Дополнительные проверки: очередь после 50 заблокированных заданий; большие одиночные входы ranking/document; общие контракты text adapters; атомарная сверка расходов без повторного платежа; миграция down/up; восстановление дампа/storage и остановка DB при ошибке. Nginx использует Docker DNS resolver, backend-сервисы используют один образ.

Ограничения: оценки очень больших входов агрегируются по частям и явно отмечены; разбиение текста может пересечь границу предложения, поэтому требуется проверка черновика. Ручная правка консервативно помечается user даже при небольшом исправлении. Исторические данные читаются без массовой переработки. Старые оценки без версии CV считаются устаревшими.

Продуктовый остаток: точность RU технических терминов (живой образец содержит ошибку), 90 уникальных проверенных вопросов, оставшиеся источники, личный сценарий владельца и сверка с кабинетом провайдера. Эти пункты не закрыты рефакторингом.
