## Транскрипты и происхождение

- Все 5 источников добавлены в административный каталог со статусом review; полные транскрипты находятся в JSONB источника и `/storage/reviewed-video-20260926/{video_id}.json`. Они не включены в исходники, CODE_SNAPSHOT или отчёт.
- `source_manifest.json`: название/автор подтверждены YouTube oEmbed, метод youtube-auto, число сегментов, SHA-256 канонического JSON, локальный путь, граница покрытия и признак отбора.
- Хэш вычисляется из `json.dumps(transcript, sort_keys=True, ensure_ascii=False).encode()`. При записи в БД хэш и число сегментов сверены. Повторное добавление источников не меняет существующие записи.
- Конец субтитров не является гарантированной длительностью видео. Поле duration_seconds оставлено 0, а не заполнено выдуманной метадатой. Платное аудиораспознавание, embeddings и извлечение через модель не вызывались.
- `documentation_manifest.json` фиксирует 9 официальных URL, конечные адреса, HTTP 200 и хэши. Полные страницы не сохраняются.

## Границы проверки

Аудио не прослушивалось. Автоматические субтитры содержат искажения технических терминов. Выбраны фрагменты с ясным смыслом; код, который виден только на экране, не восстанавливался по догадке. Эталоны — самостоятельные формулировки по документации, а не принятие любого ответа в видео за правильный. Независимая экспертная проверка не заявляется.

Исправления и уточнения: CSS-каскад шире порядка строк; union не равен type guard; default не делает параметр keyword-only; print не перебирает генератор; вывод зависит от logger и handler; три части относятся к компактному JWS, а не к любому JWT; в SQL явно различены вторая строка и второе различное значение. Рекламные и личные фрагменты не превращались в карточки. Пересекающиеся со старой базой темы замыкания, generics, HTTP-методов и изменяемых типов пропущены.
