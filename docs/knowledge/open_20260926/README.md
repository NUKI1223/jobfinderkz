## Проверка и исправления

- JS №37: пустая позиция массива не равна существующему элементу undefined; проверены hasOwn, сохранение разреженности и число вызовов callback. №50 уточняет противоположный случай: явный return без значения создаёт существующий элемент undefined. №7 избегает упрощения «== сравнивает только значения».
- Python adjacentElementProduct: варианты перебора любых пар и сортировки меняли задачу. Контрпример `[9, 1, 8]` даёт **9**, не 72. Сохранено соседство.
- first_unique_letter: удалён глобальный счётчик a–z, добавлены независимые вызовы и явный контракт Unicode-кодовых точек. При вычитке собственного условия исправлен пример: `топот` → `п`.
- find_pairs_sum_k: разные индексы, запрет повторного использования единственного элемента, удаление дублей и сортировка результата.
- Остальные Python-задачи получили контракты пустого входа, отрицательных значений, нулей и неизменности входа. Оценка умножений не обещает постоянную стоимость длинных целых.
- Page Object: бизнес-проверки находятся в тесте, но проверка загрузки/инварианта страницы допустима внутри объекта. Auto-wait клика не доказывает завершение записи на сервере. Selenium close последнего окна завершает сессию.
- Сопоставлены формулировки с прежней локальной базой. Общие темы JS/Playwright углублены отдельными случаями; одинаковые вопросы не добавлялись. Автоматическая семантическая дедупликация не заявляется.

`documentation_manifest.json` фиксирует 23 официальных URL (MDN, Python, PostgreSQL, Selenium, Playwright): HTTP 200, конечный URL и SHA-256 ответа. Полные страницы документации не сохраняются. Техническая вычитка выполнена агентом, независимая экспертная оценка не заявляется.

## Импорт

Шесть файлов `{frontend,python,qa}_{junior,middle}.json` подаются в существующий `python -m app.import_reviewed_bank`, сначала без `--apply`, затем с ним. Manifest-файлы не являются пакетами. Импорт аддитивный и идемпотентный; не переписывает прежние карточки. В allowlist добавлен только официальный `www.selenium.dev`; произвольные GitHub-страницы не становятся автоматически проверенными основаниями. Все материалы были подготовлены в файлах и проверены в изолированной БД до локальной публикации.
