# Первая подборка по открытым темам EasyOffer — 2026-09-26

12 новых RU-вопросов: Frontend junior 3, Frontend middle 3, QA junior 6; 6 практических упражнений с решениями, 13 материалов. Отбор дополняет прежние 90 оригиналов; Python пока не пополнялся из-за пересечения многих видимых тем с текущими карточками.

Источник отбора — открытые каталоги [Frontend](https://easyoffer.ru/frontend-developer/questions) и [QA](https://easyoffer.ru/qa-testirovshik/questions). В `discovery_manifest.json` сохранены доступные ссылки и хэши отрисованной страницы, без полных страниц и данных комментаторов. Точные ссылки исходных тем находятся в `review_note` карточек и доступны в редакторских данных; в пользовательских материалах показываются проверочные первоисточники. Метаданные проверки 11 уникальных официальных URL — `reference_manifest.json`.

Использованы темы вопросов, а формулировки, объяснения, рубрики и упражнения написаны заново. Платные/закрытые ответы не получались; ответы пользователей не переносились. Видеозаписи не прослушивались; карточки имеют `source_kind=documentation`, не фиктивное видеопроисхождение. Частоты, компании, имена и профили пользователей не импортировались.

Проверочные источники: официальный TypeScript Handbook, react.dev, MDN, ISTQB CTFL 4.0.1 (разделы 1.1.1, 1.3, 2.2.3, 4.4.3). Техническая редакторская проверка агентом, не независимая экспертная сертификация.

Проверки: полный набор 102 pytest в изолированной jobfinder_test. Новая регрессия импортирует все пакеты, проверяет связь с каталогом происхождения, evidence, study question/task и FTS, отсутствие Job/Usage, повторный импорт без добавлений. Для трёх TS/JS-упражнений выполнены strict tsc и runtime assertions; остальные три — сценарные QA-задания, решения проверены редакторски, не исполнены как код. UI не изменялся, браузерные E2E в этом проходе не перезапускались.

Импорт идёт через `python -m app.import_reviewed_bank`, сначала dry-run, затем `--apply`. Повтор не изменяет существующие карточки. Не импортировать manifest как пакет вопросов.
