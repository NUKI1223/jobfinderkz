## Происхождение и границы проверки

- Пять новых вопросов из сохранённого видео [UYmA6p7UwOo](https://www.youtube.com/watch?v=UYmA6p7UwOo): миксины 949.11–1000.28, access/refresh 1030.12–1046.44, N+1 1616.32–1681.2, составной индекс 2681.92–2825.0, циклический генератор 3011.92–3121.2 секунд. Текст субтитров проверен; аудио не прослушивалось, код с экрана не восстановлен. Неточные высказывания не перенесены в эталоны.
- 75 вопросов — авторские учебные формулировки по официальной документации. Это не выданные за реальные реплики записи собеседований. Материалы содержат краткое изложение, а не полные страницы.
- Ссылки, HTTP-результат, заголовок и SHA-256 прочитанного текста перечислены в [source_manifest.json](source_manifest.json). 79 URL проверены 2026-09-26. Manifest фиксирует получение источника, но сам по себе не доказывает качество эталона.
- Технические тезисы и решения прошли редакторскую сверку агентом с первоисточниками; независимая экспертная/педагогическая оценка не проводилась. Уровень junior/middle — редакторская классификация.
- В Python указаны version-sensitive оговорки: обычная/free-threaded сборка CPython, TaskGroup Python 3.11+, zip(strict=True) Python 3.10+, PostgreSQL 18 skip scan. Примеры не исполняются в пользовательском приложении.

## Проверка и воспроизведение

`docker compose -f compose.test.yaml run --rm tests` монтирует эти файлы только для чтения. `test_expansion_packages_import_retrieve_and_study` импортирует 80 вопросов в изолированную `jobfinder_test`, повторяет импорт, проверяет evidence/поиск/каталог/практику всех направлений и отсутствие Job/Usage. Видео-интервалы в этом тесте синтетические; этот тест не проверяет качество аудио.

CLI принимает один batch JSON через stdin: `python -m app.import_reviewed_bank` — dry-run; `--apply` — аддитивная публикация в локальном приложении без провайдерных вызовов. `source_manifest.json` не является batch. Существующие карточки не перезаписываются. Изменённые импортированные карточки редактируют через review-процесс, а не повторной незаметной заменой пакета.

Дополнительно исполнены 5 примеров JavaScript (замыкание, map, сравнения, microtasks, debounce) и 5 Python (циклический генератор/пустой ввод, comprehension, strict zip, восстановление ContextVar при ошибке, sqlite3 bind-параметр на синтетической in-memory БД). Остальные решения проверены по коду и первоисточникам, не заявляются исполненными.
