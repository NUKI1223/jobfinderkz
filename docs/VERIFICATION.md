## Что было исправлено по результатам тестов

- Боковое меню не прокручивалось, профиль был недоступен на экране высотой 720px.
- Неоднозначные label/select заменены явными htmlFor/id.
- Гонка между чтением records и jobs оставляла старый вопрос при завершённой оценке. Теперь сначала читается состояние jobs, затем данные, устаревшие ответы refresh отбрасываются.
- После logout лишний refresh оставлял сообщение о необходимости входа на следующей сессии.
- Мобильный текст бренда сжимал логотип.
- WebM MediaRecorder без format.duration: длительность определяется по пакетным timestamps.
- Подтверждённый ответ сохраняется до оценки, а не только после успешного ИИ-запроса.
- Миграция 0001 зафиксирована SQL-снимком и больше не меняется вместе с ORM-моделями.
- Для TXT без таймкодов требуется длительность, чтобы учитывать месячную видеоквоту.
