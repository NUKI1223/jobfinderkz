## Git: коммиты созданы, push требует входа — 2026-09-26

Созданы три коммита: приложение/интерфейс, учебные пакеты и тесты, документация/snapshot/нормализация конечных пустых строк. Проверка полного diff относительно origin/main прошла. Попытка `git push origin main` не отправила изменения: Git сообщил `could not read Username for https://github.com`. `gh auth status` подтвердил отсутствие входа; credential.helper не настроен, каталога ~/.ssh нет. Токены не запрашивались в чате и не записывались в файлы, remote не изменялся, force push не использован.

Необходимое действие владельца: выполнить в локальном терминале `gh auth login --hostname github.com --git-protocol https --web`, затем `gh auth setup-git`. После успешного входа повторить `git push origin main` и сверить remote HEAD. До этого коммиты остаются только локальными; публикация не заявляется. Эта запись включена в последний локальный документационный коммит через amend до любой успешной отправки.
